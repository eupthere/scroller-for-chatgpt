# Privacy Policy for Scroller for ChatGPT

Last updated: March 3, 2026

## Overview

Scroller for ChatGPT is a browser extension that adds a timeline-style scroll rail to improve navigation in long ChatGPT conversations.

## Data Collection

This extension does not collect, store, or sell personal data.

Specifically, the extension does not:

- Collect account credentials
- Track browsing history outside ChatGPT
- Send conversation content to external servers
- Use analytics, ads, or third-party trackers
- Sell or transfer user data

## Permissions and Why They Are Needed

### Host permission: `*://chatgpt.com/*`

The extension runs only on ChatGPT pages to:

- Detect visible conversation turns
- Build and display the timeline UI
- Scroll to a selected message when the user clicks a timeline item
- Generate short previews for navigation

All of this processing happens locally in the browser.

## Clipboard Use

The extension may access the clipboard only when the user explicitly clicks the copy action in the timeline UI.

- Clipboard actions are user-initiated
- Copied content is not transmitted anywhere
- Clipboard data is not stored by the extension

## Remote Code

This extension does not use remote code. All executable code is packaged with the extension.

## Data Storage

This extension does not maintain a remote backend or cloud database.

## Changes to This Policy

If privacy behavior changes, this policy will be updated and reflected in the extension listing.
